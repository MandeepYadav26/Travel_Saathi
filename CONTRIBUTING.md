# Contributing to Travel Saathi

Thank you for your interest in contributing to **Travel Saathi**! We welcome contributions from developers of all skill levels.

---

## 🛠️ How to Contribute

### 1. Fork & Clone
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Travel_Saathi.git
   cd Travel_Saathi
   ```

### 2. Create a Feature Branch
Create a descriptive branch for your work:
```bash
git checkout -b feature/awesome-new-feature
# or for bug fixes:
git checkout -b fix/issue-description
```

### 3. Code Style & Standards
- Write clean, self-documenting code.
- Follow standard JavaScript / React Native guidelines.
- Run `npm run lint` before committing your changes.

### 4. Commit Guidelines (Conventional Commits)
Use clear and standard commit message prefixes:
- `feat:` A new feature
- `fix:` A bug fix
- `docs:` Documentation updates
- `style:` Formatting or code style changes (no production code change)
- `refactor:` Code restructuring without changing functionality
- `test:` Adding or updating tests
- `chore:` Maintenance tasks or dependency updates

Example:
```bash
git commit -m "feat: add filter options to itinerary planner"
```

### 5. Open a Pull Request
1. Push your branch to GitHub:
   ```bash
   git push origin feature/awesome-new-feature
   ```
2. Open a Pull Request against the `main` branch of `MandeepYadav26/Travel_Saathi`.
3. Provide a clear description of your changes in the PR template.

---

Thank you for helping make Travel Saathi better for everyone! ✈️
