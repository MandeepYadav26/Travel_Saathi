# Changelog

All notable changes to the **Travel Saathi** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-08-08

### Added
- **AI Itinerary Planner**: Integration with Google Gemini 1.5 Flash API for real-time travel recommendations.
- **Travel Diary**: Memory logging, trip expense recording, and photo attachment capability.
- **Gamified Rewards Engine**: Automated calculation of travel points earned through diary activity.
- **Bookings Portal**: Segmented search interface for Hotels, Flights, Trains, and Buses.
- **Dark Mode & Haptic Feedback**: Dynamic theme switching and Expo Haptics touch feedback.
- **Authentication**: Firebase Auth integration with unique username validation.
- **TypeScript Domain Models**: Structured type definitions for core data entities in `src/types/travel.ts`.
- **Modular Utility Engine**: Utility functions in `src/utils/travelUtils.js` with node test runner suite in `src/utils/travelUtils.test.js`.
- **CI/CD Automation**: GitHub Actions pipeline for automated ESLint verification and unit testing.
- **Repository Guidelines & Templates**: Community templates for bug reports, feature requests, pull requests, and open-source contribution guidelines.
